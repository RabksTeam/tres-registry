# مستودع متجر ترس للإضافات (Tres Community Registry)

المستودع الرسمي لنشر المودات، المود باكات، الريسورس باك، والشيدرز في لانشر **ترس (Tres)**.

## شروط النشر والقبول
1. **إرفاق رابط الكود المصدري (`source_url`):** يجب أن يكون مستودع الكود المصدري عاماً (Public) على GitHub وقابلاً للمراجعة والبناء.
2. **مطابقة الملف التنفيذي:** يجب أن يكون ملف التحميل (`.jar` أو `.zip` أو `.mrpack`) مرفوعاً ضمن **GitHub Releases** في نفس مستودع الكود المصدري.
3. **السلامة والأمان:** يُمنع أي كود خبيث، سرقة جلسات/توكنات، أو تحميل ملفات تنفيذية خارجية غير معلنة.

## طريقة النشر للمطورين
1. افتح صفحة **نشر إضافة جديدة** من داخل برنامج **ترس** (قسم لوحة المطوّر -> `🚀 نشر على متجر ترس (GitHub)`).
2. سيعمل نظام الفحص الآلي (`GitHub Actions`) للتحقق من رابط الكود المصدري وملفات البناء ورابط التحميل.
3. بعد اجتياز الفحص، يقوم مشرف المتجر بمراجعة الكود المصدري وقبول الطلب (**Merge**) ليظهر تلقائياً في **catalog.json** وداخل برنامج ترس.
